<h2 align="center">✦ One workspace. More capable AI. ✦</h2>

<table>
  <tr>
    <td width="50%" valign="top">
      <h3>🧠 Live-validated AI</h3>
      <p>Connect Google Gemini or Groq. Vednix discovers models from provider APIs and checks their capabilities before offering them for use.</p>
    </td>
    <td width="50%" valign="top">
      <h3>⚡ Smart routing</h3>
      <p>Choose a provider and model, or use priority-based automatic routing with failover before the first response token.</p>
    </td>
  </tr>
  <tr>
    <td width="50%" valign="top">
      <h3>💬 Real-time chat</h3>
      <p>Streamed responses over WebSockets, with conversation history and multilingual chat for Hindi, Hinglish, and English.</p>
    </td>
    <td width="50%" valign="top">
      <h3>📄 Understand your files</h3>
      <p>Validated document uploads, server-side PDF text extraction, and image input routed to vision-capable models.</p>
    </td>
  </tr>
  <tr>
    <td width="50%" valign="top">
      <h3>🔐 Keys stay protected</h3>
      <p>Provider API keys are encrypted on the backend and are not returned to the browser.</p>
    </td>
    <td width="50%" valign="top">
      <h3>🗂️ Built for continuity</h3>
      <p>Conversation memory, a searchable knowledge base, browser-based voice features, and optional SearXNG web research.</p>
    </td>
  </tr>
</table>
